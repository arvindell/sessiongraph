# SessionGraph v1.0.0

**Explore & visualize all your LLM sessions**

## Twelve coding agents, one local library

Gemini CLI, Qwen Code, Pi, GitHub Copilot CLI, Cline, Roo Code, Kilo Code's legacy extension history, and Continue join OpenCode, Claude Code, Codex, and Cursor.

- Search across saved conversations and explore messages, tools, recorded reasoning, and changed-file evidence.
- Preserve explicit forks, child sessions, and in-file branch links without guessing ancestry or missing timestamps.
- Continue in eight CLI destinations, using native resume where supported or a local saved-context handoff.
- Find sources quickly in Settings and Manage sources; detected and previously selected sources appear first.
- Auto-import selected sources by default, with a persistent off switch. Time ranges, filters, and appearance preferences survive restarts.

Import, search, and visualization run locally. Imports are read-only and never start an AI agent. Saved history remains available when a source is offline or deselected.

Source coverage varies: Kilo support covers legacy extension task JSON, and some conversation snapshots omit earlier compacted content, attachments, or metadata. See the [source coverage guide](https://github.com/arvindell/sessiongraph/blob/v1.0.0/docs/guide.md#source-coverage).

## Install

Native downloads are available for macOS Apple Silicon/Intel, Windows x64, and Linux x64/ARM64. Desktop updates verify signed, version-bound packages.

With Node.js 24+:

```sh
npx sessiongraph@1.0.0
# Or open the browser edition with its local backend:
npx sessiongraph@1.0.0 --browser
```
