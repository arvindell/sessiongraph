# SessionGraph v1.0.1

**Explore & visualize all your LLM sessions**

- **Moving orbs:** sessions appear at creation and travel with time, leaving their trails behind before resting at the latest saved message.
- **Cleaner conversations:** message dots match their session orb. The message browser shows user and assistant messages with simple Previous / Next navigation.
- **Better defaults:** start with **All time** and archived sessions hidden. **Settings → Interface → Show archived sessions** brings them back; saved choices remain honored.
- **Keep your place:** manual and automatic refresh preserve camera position, zoom, and session/message selection. Added history keeps existing layout positions and directory colors stable. **Fit view (F)** explicitly reframes the map.
- **Twelve recognizable sources:** locally bundled icons throughout the app, with compact source options showing detection status and saved counts. All twelve fit in the desktop picker without searching.
- **Clearer focus:** stronger dimming for surrounding nodes, halos, and trails. Click or tap empty map space to deselect; panning and orbiting keep your selection.
- **Smoother demo:** a new 60 FPS video with gentle zoom, orbit, timeline playback, message exploration, conversation search, and the compact source picker. All demo sessions are synthetic.

## Update

Use the desktop **Update** pill to download and verify the update, then choose **Restart** when ready. Native downloads are available for macOS Apple Silicon/Intel, Windows x64, and Linux x64/ARM64.

With Node.js 24+:

```sh
npx sessiongraph@1.0.1
# Browser edition:
npx sessiongraph@1.0.1 --browser
```
