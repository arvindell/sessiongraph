Privacy Policy

Your session history stays on your device. SessionGraph imports, searches, and renders it locally. You don’t need an account, and the app doesn’t sync your library to the cloud or send analytics or crash reports.

What we store when you publish

Publishing is optional. The app prepares a preview on your device. Only after you confirm do we replace your previous public graph with the approved snapshot. Signing in or importing more sessions does not publish or update a graph.

  • Always included: numeric IDs and groups specific to the graph, plus recorded parent and fork links between the selected sessions.
  • Only if enabled: token counts, session timestamps, message counts and timestamps, recognized model names, and coding-tool names. Fields you turn off are not uploaded.
  • Never included: messages, code, tool inputs or outputs, project or session names, file paths, native session IDs, credentials, or costs.

Anyone can view your graph at /@your-github-username or find it in Explore graphs. That page can show a thumbnail generated from the public snapshot, the session count, and a token total if shared. It can’t read your local library. Your profile is tied to your GitHub username, and published activity or timestamps can reveal work patterns.

Website and account data

When you sign in, we store your GitHub user ID and username, hashed login tokens, and short-lived desktop sign-in approval records. Browser sign-in uses cookies. We don’t request repository access, and we discard the GitHub OAuth token after sign-in. If you use organizations, we store organization names, slugs, memberships, and invitations; membership does not grant access to local sessions.

Vercel handles website and API requests, and AWS stores hosted records. Hosting providers receive ordinary connection information, such as IP addresses. SessionGraph uses short-lived hashed request identifiers for rate limiting. Desktop update checks contact GitHub, and npm installs contact the npm registry; neither sends session history.

Your controls

Use Unpublish from the app or your account to remove the hosted graph. Signing out doesn’t remove it, and unpublishing can’t erase copies others already saved. SessionGraph doesn’t encrypt local library or handoff files; your device and backup settings govern access to them. If you continue a session in another coding tool, that tool’s privacy settings apply to the context it receives.
